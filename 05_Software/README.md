# 💻 OpenCADStudio

Este directorio está destinado a los binarios de ejecución e instalación de OpenCADStudio.

- **OpenCADStudio.exe**: Aplicación CAD portable v2026.42 (integrada vía MCP CADCraft / OpenCADStudio).
- **OpenCADStudio-installer.msi**: Paquete de instalación para sistemas Windows.

> **Nota:** Los archivos ejecutables e instaladores (`.exe`, `.msi`) están excluidos del seguimiento de Git para cumplir con las políticas de tamaño de archivo de GitHub (<100 MB) y mantener el repositorio ágil y limpio.
